# mtavault: dl

A fast, lightweight microservice built with Bun and Hono for streaming files on demand with maximum efficiency.

## Run Locally

Clone the project

```bash
  git clone https://github.com/mtavault/dl
```

Go to the project directory

```bash
  cd dl
```

Install dependencies

```bash
  bun install
```

Start the server

```bash
  bun run dev
```

## Config

To run this project, you will need to add the following config variables to your app.config.ts file

`port`

`mtavault_api`

`storage_location`
